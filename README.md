# HSKもじバトル（汉字大战）— HSK1単語バトルゲーム

中国語を学ぶ日本の大学生向けの、ドット絵風の単語練習ゲームです。正解すると攻撃が出て、まちがえるとHPが減ります。

- **ビルド不要・外部ライブラリなし。** `index.html` をブラウザで開くだけで動きます（ダブルクリックでもOK）。
- **GitHub Pagesにそのまま置けます。** フォルダごとリポジトリに入れてください。
- マウス・キーボード（1〜4で解答、スペースで音声、Escでポーズ）とスマホのタップに対応しています。縦画面向けのレイアウトです。

## あそびかた
1. 「はじめる」を押します。初回はチュートリアル（5問）です。ダメージはなく、正解するまで先に進めません。
2. ステージは全11（HSK1の150語を12〜15語ずつ、テーマ別に分けています）。
   - **ザコ敵**：1語に1問。出題形式は「漢字→意味」「漢字→ピンイン（声調つき）」「意味→漢字」の3つです。まちがえた単語は、ステージの後半に別の形式でもう一度出ます。
   - **中ボス**（ステージの半分の地点）：3回正解で撃破、HPが1回復します。
   - **ボス**：「リスニング（読み上げを聞いて単語を選ぶ）」と「声調（同じピンインで声調だけちがう4択）」で、5回正解すると撃破です。
3. HPは5です。まちがえるか時間切れ（ザコ15秒、ボス20秒。設定でオフにできます）で1減り、0になるとゲームオーバーです。
4. ボスを倒すと次のステージが解放されます。
5. 結果画面には正答率、スコア、今回まちがえた単語、これまでよくまちがえた単語（🔊で読み上げ）が出ます。
6. 「まちがえた単語を復習」では、ミスの多い単語（最大12語）で専用ステージを遊べます。復習で正解するとミス回数が1減ります。

記録（解放状況、ベストスコア、ミス回数、設定）は、端末のブラウザの `localStorage`（キー `hskMojiBattle.v1`）に保存されます。サーバーには何も送りません。

## 音声
音声はブラウザの読み上げ機能（Web Speech API `speechSynthesis`）で、中国語（zh-CN）の音声を使います。
- 端末に中国語の音声がない場合は画面に案内を出し、リスニング問題はピンインを表示する形で出題します。
- iPhoneでは、最初のボタン操作のときに音声を有効にしています。
- 声の種類や品質は端末によって変わります。

## 単語データの出典
- 漢字・ピンイン：**complete-hsk-vocabulary**（drkameleon, https://github.com/drkameleon/complete-hsk-vocabulary）
  - `wordlists/exclusive/old/1.json`（旧HSK1級・150語）
  - **MIT License**（Copyright (c) 2026 Yanis Zafirópulos）
  - 同リポジトリの元データは clem109/hsk-vocabulary で、英語の意味はCC-CEDICTです（このゲームでは英語は使っていません）。
- ピンインは出典の数字表記（例：`ni3`）から声調記号を付けて表示しています。150語すべてで、出典の声調記号表記と一致することを確認済みです。
  - 例外は「女儿」の音節区切りの「'」（nǚ'ér）だけです。
  - 多音字（33語）は出典の複数の読みからHSK1で使う読みを1つ選びました。`words_check.csv` の「多音字メモ」列に、選ばなかった読みを書いています。
- **日本語訳は、AIが作成したものです。先生の確認が必要です。** `words_check.csv`（Excelで開けます）で確認・修正してください。
  - 修正するときは `tools/make_words.py` の訳を直し、`python3 tools/make_words.py 1.json` で `data/words.json` と `data/words.js` を作り直します。

## ファイル構成
```
index.html        画面
css/style.css     見た目
js/pinyin.js      数字ピンイン→声調記号
js/art.js         ドット絵（すべてこのゲームのために描いたオリジナル）
js/game.js        ゲーム本体
data/words.js     ゲームが読み込む単語データ（file://でも動くようJS形式にしています）
data/words.json   同じ内容のJSON
words_check.csv   先生の確認用（漢字・ピンイン・日本語・ステージ・出典）
tools/make_words.py  単語データの生成スクリプト
```
